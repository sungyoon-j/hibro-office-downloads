## 설치 방법

- **Mac:** DMG를 열고 HiBro Office를 응용 프로그램 폴더로 옮긴 뒤 실행하세요. Mac 종류를 모르면 Apple 메뉴의 ‘이 Mac에 관하여’에서 칩 또는 프로세서를 확인하세요.
- **Windows:** EXE 설치 파일을 실행하세요. 현재 Windows판은 시험판입니다.
- **기존 사용자:** 열려 있는 문서를 저장하고 HiBro Office를 종료한 뒤 설치하세요. 문서 원본과 백업은 보관하세요.

문서 형식과 사용한 기능에 따라 지원 범위가 다릅니다. 원본을 보관하고 사본에서 표시와 저장 결과를 먼저 확인해 주세요.
